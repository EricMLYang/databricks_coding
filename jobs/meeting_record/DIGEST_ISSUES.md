# 週 / 月 AI 彙整會遇到的問題

會議紀錄 → 條目 → 週報（語意 / 情報台帳）→ 月報（Sales Brief 對照）這條線，實際跑過一輪後整理的問題清單。每題寫「現象、影響、現在怎麼處理、還要決定什麼」。依發生的階段排，不依嚴重度。更新日期 2026-10-20（下午：使用者定優先序後 D33 已處理的題標 ✅，見各列「待決」欄）；樣本依據：2026-08 acer × MNT 月報預覽（2 封信、30 條）與 Stage B 第一次全量（446 條 intel）。

## 6. 做決定時的順序建議

1. 版面（4.1 / 4.2 / 4.3）→ 決定 W2 要建什麼。
2. PM 開始審 semantic 190 條（3.1）→ 台帳才有正式 SEM。
3. 台帳與 md 正本（4.6）→ 決定 Stage B md 怎麼貼回。
4. prompt 0.3 一次解 1.4 / 2.1 / 2.2 / 2.5（全量重萃只付一次）；之前先做 golden set（5.4）。
5. ETL 截斷（1.1）平行找 owner。
