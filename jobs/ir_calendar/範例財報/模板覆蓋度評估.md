## 3. 可以自動填的（已在 build_report.py 實作）

- **KPI**：最新季 `revenue / gross_margin / operating_margin / current_ratio`；YoY 用去年同季列算（五家都有 2025Q2）。
- **近五年**：annual 列的 `revenue / pretax_income / net_income / net_margin / eps`，採購判讀由淨利正負與淨利率自動給燈。
- **季度**：當年度 quarterly 列；「重點」欄用 `operating_income` 與 `pretax_income − operating_income` 自動判「本業獲利／本業虧損／業外帶動」。
- **資產負債**：`total_assets / total_liabilities / debt_ratio / current_ratio`。
- **示範分數**：§5 的規則，全部來自 `fin_rows`，不需人工。
- **資料來源**：`source_urls`（MOPS t164sb03/04/05 或 SEC companyfacts）、`docs.source_url`、`summary.sources`、`company.ir_url`。

## 4. 填不滿或要注意的

### 4.1 資料缺（pipeline 補得到）

1. **法說摘要只有 2/5**：奇美、永光 `summary = null`，Corning 也是 null 但 `docs[0]` 是財報新聞稿（Exhibit 99），這次是人工從新聞稿摘錄管理層觀點。→ 沒有 summary 的公司，模板的「管理層觀點」「Watchlist」「QBR 必問」三節只能靠財報數字反推，內容會薄。
2. **`summary` 的結構化欄位沒在用**：`headline_metrics / management_views / positive_signals / watch_items / open_questions` 五個欄位都存在、五家全 null。這五個欄位正好對應模板第二、六、七、八節；填起來模板就能全自動。
3. **季度 OCF／資本支出只有 YTD**：quarterly 列的 `operating_cash_flow / capex` 皆 null，只有 `*_ytd`。模板「現金流與資產負債（期間）」要的是當期數字，目前只能標「年初累計」。單季值 = 本季 YTD − 上季 YTD，可在 pipeline 算（Q1 例外：YTD 即單季）。
4. **Corning `capex / equity / investing_cash_flow` 為空**：SEC companyfacts 的 tag 沒對到（capex 通常是 `PaymentsToAcquirePropertyPlantAndEquipment`）。
5. **奇美只有 2 個季度列**（2025Q2、2026Q2），缺 2025Q1/Q3/Q4、2026Q1，季度表只有一列，看不到趨勢。其他四家是完整的。
6. **奇美主檔缺 `industry / website_url / ir_url / market_type / profile_source`**，模板頁首的產業欄只能標缺。永光英文名被截斷（`Corporatio`）。
7. **南亞 `period = 2026Q3` 但財務列只到 2026Q2**：法說是 2026-10-13 講 Q3 展望，Q3 財報未出。報告頁首要分開標「財務 2026Q2 ＋ 法說 2026Q3」，否則讀者會以為 KPI 是 Q3。
8. **fin_rows 沒有部門別**：War Room「本業 vs 新事業」的驗證只能用合併數字。Corning 新聞稿、南亞簡報裡都有部門別表，但沒進資料表。

### 4.2 口徑問題（報告裡已註明，pipeline 端要決定）

1. **稅後淨利 = 合併淨利（含非控制權益）**，`net_income_parent` 只有 2026 季度列有值。奇美 2026Q2 合併淨利 4.36 億 vs 歸屬母公司 9.75 億，差一倍以上；長興 8.70 vs 8.47。EPS 是用母公司淨利算的，所以表上「淨利為負、EPS 為正」會出現（奇美 2023）。建議 fin_rows 全列補 `net_income_parent`，模板用母公司口徑。
2. **2025Q4 列是推算的**（`derived` 標了 `revenue / net_income`，台股缺 `gross_profit / operating_income`）。若模板要顯示去年 Q4，毛利率、營益率會是空的。
3. **長興的 summary 來自媒體，有錯**：「上半年營業利益率 24%」（財報營益率 8.59%，24% 接近毛利率）、「負債比率由 180 降至 174」（口徑不明）。War Room 的「財務驗證」欄剛好抓出來，但這代表媒體來源的 summary 要標信心等級。
4. **單位**：台股千元、美股元；報告統一換算成「億」，Corning 以億美元顯示、不換台幣。模板的 `NT$` 字樣要改成依幣別帶入。
5. **docs 文字匯出截斷在 20,006 字**（`truncated_for_export: true`），財報 PDF 的現金流量表、附註都不在匯出內；想從財報 PDF 補表（例如單季 capex、保留結論的子公司明細）得讀 Volume 上的原檔。

### 4.3 模板本身要人寫的

一句話判讀、採購決策提示（4 條）、QBR 必問（5 題）、War Room 的 AUO 判讀燈、Watchlist 三段（10 條）、限制說明。這次五家共約 150 條敘事是人寫的（在 `build_report.py` 的 `NARRATIVE`），數字全部從 `fin_rows` 帶入不手抄。要自動化就是 LLM 讀 `fin_rows` + `summary` 生這些欄位，與 HANDOFF 提到的「財報數據管線」（open loop #48）分工：數字管線不碰 LLM，敘事由 LLM 生、人審。

## 5. 示範分數規則（build_report.py `score()`）

滿分 100，全部用 `fin_rows` 最新季與近五年 annual 列：

| 項目 | 配分 |
|---|---|
| 最新季稅後淨利率 | >10% 15／5–10% 10／0–5% 5／<0 0 |
| 最新季營業利益率 | 同上 |
| 營收 YoY | >10% 10／0–10% 6／−10–0% 3／<−10% 0 |
| 負債比 | <40% 15／40–60% 10／>60% 5 |
| 流動比率 | >2x 15／1.5–2x 10／1–1.5x 5／<1x 0 |
| 營業現金流（YTD） | 負 0／正但 <50% 淨利 5／其餘 10 |
| 近五年虧損年 | 無 10／有但非最近一年 5／最近一年虧損 0 |
| 毛利率較去年同期 | 改善 10／否則 0 |
| 業外依賴 | 業外 > 本業扣 5 |

燈號：≥70 🟢 維持往來／40–69 🟡 加強監控／<40 🔴 降載。是示範用，模板自己也寫「非信用評等」；門檻可依採購需求調。

## 6. 怎麼重跑

```
cd jobs/ir_calendar/範例財報
python3 build_report.py      # 讀同資料夾 5 份 .md，輸出同名 .html
```

換新一季資料：把新的 JSON 蓋掉 `.md`，重跑即可；數字會更新，`NARRATIVE` 裡的敘事要人重看（含幾個寫死的歷史數字，如 2025 全年營收）。
