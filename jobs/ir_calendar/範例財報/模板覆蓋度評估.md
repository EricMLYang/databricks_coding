## 4. 圖表怎麼產

模板的 12 張圖是 base64 PNG（推測 matplotlib 離線畫，占檔案 500 KB／521 KB）。這次改成**純 Python 產 inline SVG**（`build_report.py` 的 `svg_bars` / `svg_rev_opm`）：
無套件依賴、向量可印、每家整頁 50–74 KB、滑鼠停留顯示數值、缺值直接留空並標「推算列無 OPM」／「該年來源無值」。配色沿用模板（柱 #cfeafa 淺藍、折線 #7752A8 紫、標記 #F5C400 黃）。

進 `build_supplier_report` 管線時同一套函式可直接用：`fin_rows` → SVG 字串是純函式，可進 `tests/`；要與模板外觀完全一致再改 matplotlib（DBR 內建，但中文字型要先裝）。

一個設計差異：模板第 04／05 節把 OPM 折線疊在營收金額軸上（雙軸、OPM 無自己的軸），讀者容易把折線高度當金額比例；這裡改成**上下兩格共用 x 軸**（上：營收柱，下：OPM 折線），資料需求不變。要回到單格疊圖只改 `svg_rev_opm`。

## 8. 怎麼重跑

```
cd jobs/ir_calendar/範例財報
python3 build_report.py      # 讀 <公司>/<公司>.md 與 <公司>_爬蟲*.md（含 _新版實測），輸出報告＋來源頁到同資料夾 + index.html
python3 build_sources.py     # 只產來源檢視頁
```

檔名規則：`<公司>_爬蟲[_<期別>][_新版實測].md` → `<公司>_爬蟲資料[_<期別>][_新版實測].html`；檔名含「新版實測」即視為新版（financials 以 `quick_ratio`、summary 以 `management_views` 鍵再確認）。
有新版 financials 時報告財報六節改用新版列，console 會印共同欄位比對結果（`same / filled / diff`），`diff > 0` 時頁首與附錄會標示。
換新一季資料：新的 bundle JSON 蓋掉 `<公司>/<公司>.md`、Databricks 印出的 payload 存成 `<公司>_爬蟲_<期別>.md`（印法見 HANDOFF §5 與 `inspect_record`），重跑即可；新版進 Databricks 後，payload 格式相同，檔名去掉 `_新版實測` 也會被同樣辨識。
`NARRATIVE` 的結論與限制文字要人重看。
