# 供應商「財報＋法說整合報告」模板與使用者說明

- 模板檔：`20261010_供應鏈供應商財務體質報告模板.html`（2026-10-20 自 MI_Crawler `ir_calendar/doc/` 複製，原檔不改）。
  job 只沿用它的**配色、字體、卡片、表格、段落層級**（CSS 已原樣內嵌在 notebook [c07]），章節順序改依下方使用者說明。
- 使用者（採購端）2026-10-20 提供的模板說明原文在 §1；§2 是 job 怎麼對應每一條；§3 是刻意不做的事。

## §1 使用者說明原文（照錄）

> 請以我附件「SCM財報和法說報告html格式 v20261007.html」作為唯一版型，製作【供應商名稱】【財報期間】的 AUO 採購用「財報＋法說整合報告」，並輸出完整、可單獨開啟的 HTML 檔案。
>
> 一、版型與順序
> 1. 保留附件的 AUO 配色、字體、表格、卡片、段落層級與單欄圖表排版，不要重新設計。
> 2. 報告標題與期間之後，先放獨立段落「給 AUO 採購主管的結論」，再放「財報資訊」，最後放「法說會資訊」及資料來源。
> 3. 採購結論聚焦供應穩定性、成本與議價、付款條件、替代料或驗證風險。區分已證實事實、管理層展望與採購建議，不把公司整體財務變動直接推論為個別料號的漲價理由。
>
> 二、財報資訊
> 保留財報重點、財報實績、事業群財務表現，以及五年、五季「營收 × OPM」趨勢圖。營收使用淺藍色柱狀圖，OPM 使用紫色折線；營收數字放在柱內中間偏上。所有數字標籤不得互相遮蓋，也不得被折線或圖例遮蓋。
> 另提供近五年財務指標表格，包含：營收、毛利率、淨利率（稅前）、稅後淨利率、EPS、營業現金流、負債比、流動比、速動比、應收天數、應付天數。上方已有五年營收圖，下方指標區只畫其餘十項的五年趨勢，不要重複畫營收圖。十項圖表每張獨立一列，圖面寬度與留白比照上方五年營收圖，不要兩張並排；維持一致的淺藍柱狀與紫色趨勢線風格。
>
> 三、法說會資訊
> 依附件章節呈現：事業體／產品線重點、擴產／產能變化、獲利能力變化、未來市場預測、投資／M&A／組織整改、與 AUO 業務及 Micro LED 相關議題、Q&A 重點。資料未提及的事項請寫「未提及」，不得推測合作關係或供應項目。
>
> 四、資料與示意值
> 優先使用公司公告、年報、財報及法說資料，逐項核對數值、單位、期間和計算口徑。若本次僅為展示 HTML 模板，可為缺值填入合理示意數字，但必須在該區醒目標示「模板示意資料，非公司財報實績」，且不得將示意值用於採購結論。若本次要求正式報告，絕不可假設數字；缺值標示「未取得」，不畫虛構趨勢。
>
> 五、交付前檢查
> 確認採購結論位於「財報資訊」上方、下方沒有重複的五年營收圖、其餘十項指標圖均為單欄、圖上數字不重疊、表格與圖表數值一致、示意資料有清楚標示，且 HTML 內嵌圖片可正常顯示。只交付最終 HTML 檔案及簡短的資料口徑說明。

## §3 刻意不做 / 已知限制

- 速動比、應收天數、應付天數：`s_ir_calendar_financials` v1 沒有存貨、應收帳款、應付帳款、銷貨成本（台股）欄位，算不出來。要補得先在爬蟲端 `financials.py` 加欄位 → `init_tables` ADD COLUMNS → `consume_batches` [c04] / [c06] → 本 job [c02] `INDICATORS` 改 `source`。
- 非台股 / 美股公司（TYO、KRX、SZ、HK…）目前沒有結構化財報 → 報告的 KPI、實績表、指標表、所有圖都是「未取得」，只有 LLM 從文件整理的文字段落。
- 事業群財務表現：只有文件有分部資料時 LLM 才填，否則「未提及」；不從 financials 推。
- 圖表是 SVG 不是 PNG：可單獨開啟、列印、不依賴 JS 與外部字型；若收件系統只收 `<img>`，再加轉檔步驟。
